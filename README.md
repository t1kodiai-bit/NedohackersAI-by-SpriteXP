# NedohackersAI by SpriteXP

**Универсальный ИИ-помощник для решения самых разных задач.** Помогает в разработке программ для конкурсантов, и разблокировки системы.

## 🆓 Полностью бесплатно
Мы используем бесплатные модели через OpenRouter, поэтому пользоваться чатом можно без оплаты и встроенных лимитов со стороны нашего сайта.

## ⚡ Быстрый доступ
Никакой регистрации и создания аккаунта — просто откройте сайт и начните пользоваться ИИ.

## ⚠️ Важное предупреждение
На данный момент функция сохранения истории чатов отсутствует. Рекомендуем самостоятельно сохранять важные переписки на своём устройстве, чтобы не потерять нужную информацию.
